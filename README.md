# Cyber Challenge 2026

تجربة توعوية في الأمن السيبراني باستخدام Node.js + Express.

## المتطلبات

- Node.js 18 أو أحدث
- متصفح حديث يدعم Camera API

## التشغيل

داخل مجلد المشروع:

```bash
# تثبيت التبعيات
npm install

# تهيئة حساب الأدمن الافتراضي
npm run init-admin

# تشغيل الخادم
npm start
```

ثم افتح:

```text
http://localhost:3000
```

### الدخول إلى لوحة التحكم

بعد تشغيل `npm run init-admin`، يمكنك الدخول إلى لوحة التحكم:

```text
http://localhost:3000/admin
```

**بيانات الدخول الافتراضية:**
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

تنبيه امني: يرجى تغيير كلمة المرور بعد الدخول الأول!

## ملاحظات الكاميرا

المتصفح هو الذي يتحكم في نافذة طلب صلاحية الكاميرا.

بعد موافقة المستخدم:
1. يتم تشغيل الكاميرا.
2. لا يتم عرض معاينة الفيديو للمستخدم.
3. يتم التقاط صورة واحدة.
4. يتم إيقاف جميع مسارات الكاميرا مباشرة.
5. تُرفع الصورة إلى الخادم.
6. يُحفظ سجل المشاركة في SQLite.

## مسارات مهمة

- `/` صفحة التحدي
- `/admin` لوحة تحكم الأدمن
- `/success` صفحة نجاح المشاركة
- `/awareness` صفحة التوعية
- `/api/status` فحص الخادم
- `/api/stats` إحصائيات بسيطة

## API Endpoints

### المشاركين
- `POST /api/participants` - تسجيل مشارك جديد (مع صورة)
- `GET /api/stats` - الحصول على إحصائيات عامة

### الأدمن (محمي بالمصادقة)
- `POST /api/admin/login` - دخول الأدمن
- `POST /api/admin/logout` - خروج الأدمن
- `GET /api/admin/status` - التحقق من حالة المصادقة
- `GET /api/admin/participants` - الحصول على قائمة المشاركين
- `DELETE /api/admin/participants/:id` - حذف مشارك

## التخزين

- الصور: `uploads/`
- قاعدة البيانات: `database/cyber_challenge.db`

> قبل استخدام المشروع في فعالية حقيقية، راجع سياسة الخصوصية والموافقة والاحتفاظ بالصور، واستخدم HTTPS عند النشر.
